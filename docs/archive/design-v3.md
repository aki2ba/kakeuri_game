## 1. 企画概要

### 1.1 一言でいうと

プレイヤーは卸売会社の社長になり、**36ヶ月（3年）を、会社を潰さず・焦げ付きを出さずに乗り切る**。最大の敵は競合ではなく、**売った代金が返ってこないこと**、そして**返ってくるのが遅すぎること**である。

大儲けを目指すゲームではない。粗利率16%・営業利益率1%台という卸売業の実態（§2.4）では、3年で会社を大きくすることはできない。**1件の事故で積み上げた利益を吹き飛ばさないことが、この商売の勝ち筋**である。勝利条件をそう設計した（§3.4）。

ただし縮こまっていても勝てない。人件費は毎年上がり、取引先の発注は放っておくと減る。**守るために攻めなければならない**という板挟みが、このゲームの基本姿勢である。

### 1.2 このゲームで体で覚えてもらう3つのこと

1. **黒字でも現金が尽きれば倒産する**（利益と現金は別物。手形と長期サイトがこれを引き起こす）
2. **支払条件は値段と同じくらい重要**（「いくらで売るか」より「いつ入るか」で会社が死ぬ）
3. **焦げてからできることは、焦げる前に何をしたかで決まる**（担保も保証人も公正証書も、危なくなってからでは取れない）

3番目が本ゲームの中核である。プレイヤーは必ず一度は「事後に手を打とうとして、打てるものが何も残っていない」状況を経験する。

そのうえで、**回収では取り返せない類型がある**ことも体験させる。取り込み詐欺（§4.9）と架空循環取引（§4.10）である。相手が最初から払う気がない、あるいは取引自体が架空なので、督促も担保も差押えも効かない。**予防しか手段がない**という一点を、痛みを伴う形で伝える。

### 1.3 ターゲット読者・プレイヤー

- 与信管理・債権管理の業務に関わり始めた人（開発者、営業、カスタマーサポート）
- 「掛売り」「支払サイト」といった語を聞いたことはあるが、実務経験がない人

### 1.4 遊んで身につくもの

| カテゴリ | 具体的に身につくこと |
|---|---|
| 商習慣 | 締め日・支払月・支払日から支払サイトを読む／手形サイトを足して考える／手形ジャンプ／支払条件の変更が危険信号である理由 |
| 与信管理 | 与信枠は有限であり配分するものだという感覚／必要限度と安全限度／自己資本比の目安が中堅企業には素朴に使えない理由／取引シェアの危険 |
| 債権保全 | 連帯保証人・物的担保・公正証書を**取引開始時に**取る意味／保全を求めることは値引き・サイト延長との交換であるという交渉の実際 |
| 債権回収 | 督促と催告の違い／内容証明の効果／相殺／動産売買先取特権／債権譲渡と対抗要件／法的手続に進む判断／破産時に何が起きるか |
| 不正の見抜き方 | 取り込み詐欺の助走パターン／商業登記から読み取る危険信号／架空循環取引に組み込まれる構造 |
| 在庫・仕入 | 在庫は現金が形を変えたものである／仕入先の選び方が回収手段を左右する（相殺）／免税事業者から仕入れることの意味 |
| 法令 | 消滅時効と完成猶予／債権譲渡の第三者対抗要件／根保証の極度額／取適法（特定運送委託の追加を含む）／支払期日60日ルール／貸倒損失 |
| 会計・財務 | 黒字倒産のメカニズム／貸倒損失の計上判断と税負担 |

### 1.5 非ゴール（やらないこと）

- **売掛保証サービス・取引信用保険を題材にしない**（理由は §6.1）。リスクを外部に移す手段としては、買取型ファクタリング（＝債権譲渡）のみを扱う
- 財務三表の完全なシミュレーション（損益計算書と現金残高の簡易版までとする。税は実効税率の1行モデル）
- 訴訟手続の詳細な再現（申立て・審理・判決を1アクション1判定に圧縮する）
- 対戦・マルチプレイ
- モバイル最適化（タブレット以上の画面幅を想定）

## 2. 舞台設定

### 2.1 プレイヤー

**関東の中堅食品卸「株式会社カケウリ商事」の二代目社長**。父から会社を引き継いだ直後からゲームが始まる。

### 2.2 なぜ卸売業を舞台にするのか

1. **取引先の社数が多く、1社あたりの単価は中程度**。「限られた与信枠を、どの取引先にどう配分するか」という判断が毎ターン発生する
2. **売り先の業種を混在させられる**（小売・飲食・建設・製造・EC など）。業種ごとに支払条件やリスクが違うことを自然に表現できる
3. **粗利率が薄い**（16%）。1社の焦げ付きが年間利益を吹き飛ばすため、与信判断の重みが実感しやすい
4. **物を納品する商売なので、回収法務の選択肢が広い**。商品の引揚げや動産売買先取特権といった、物があるからこそ使える手段を扱える。サービス業を舞台にするとこれらが使えない
5. **仕入と販売の両方を持つ**ので、相殺（§5.4）を能動的に作れる

### 2.3 初期状態

| 項目 | 値 |
|---|---|
| 現金 | 3,000万円 |
| 自己資本 | 5,000万円 |
| 月商 | 4,000万円 |
| 粗利率 | 16% |
| 固定費 | 月590万円（毎年4月に人件費が+25万円/月ずつ上昇） |
| 売掛残高 | 8,000万円（月商 × 平均サイト2ヶ月） |
| **総与信枠** | **1億円**（自己資本 × 2.0倍。§4.4） |
| 既存取引先 | 6社。うち1社が売上の35%（月1,400万円・売掛残高2,800万円） |
| 保全状況 | 全取引先について**何も取っていない**（基本契約書のみ） |
| 先代からの負の遺産 | 回収を放置した売掛金1件（430万円）。第14ターンに時効を迎える |
| 目標 | 36ターン生存し、焦げ付き純損失を抑える（§3.4） |

初期状態には**2つの罠を意図的に仕込んでいる**。

**罠1: 保全が何もない。** 既存取引先に後から連帯保証人を求める難しさ（§4.7）を早い段階で味わう。

**罠2: 総与信枠の80%が既に埋まっており、しかも1社に偏っている。** 売上35%の取引先の残高2,800万円は、その格付（上位）の上限1,400万円を大幅に超えている。先代が枠管理をしていなかったという設定である。

超過分は**経過措置として許容し、警告を表示するだけ**にする（実務でも既存与信の是正には時間がかかる）。ただし**その取引先への増額はできない**。プレイヤーは「減らすには売上を落とすしかない」というジレンマを最初から抱える。これが §4.5 の取引シェア問題を、説明ではなく初期状態として体感させる。

格付が未定義だと限度額の初期値も交渉余地も決まらないため、6社すべてを定義する。**超過しているのは主要1社だけ**になるよう格付を割り当てている。

|---|---|---|---|---|---|---|---|---|

| 城南商会 | 小売 | 520万 | 末締め翌月末（2.0ヶ月） | 1,040万 | 72 | 最上位 | 1,200万 | 0 |
| みなと水産 | 小売 | 520万 | 末締め翌月末（2.0ヶ月） | 1,040万 | 65 | 上位 | 1,200万 | 1 |

| 三葉フーズ | 小売 | 520万 | 末締め翌月末（2.0ヶ月） | 1,040万 | 64 | 上位 | 1,200万 | 1 |

限度額の合計8,800万円は総与信枠1億円の88%を占める。**残りは1,200万円しかない**ので、第1ターンから枠の配分を考えることになる。

交渉余地が0の相手（最上位2社）からは、追加の保全を一切取れない。**格付が高い相手ほど交渉力も強い**（§6.9(e)）という設定が、初期状態にも現れている。

### 2.4 収支の設定根拠（公的統計に合わせた）

粗利率と固定費は、経済産業省の商工業実態基本調査（中小企業実態基本調査）の実態値に合わせている。

| 指標 | 統計値 | 本ゲームの設定 |
|---|---|---|
| 売上総利益率（粗利率） | 卸売業平均 11.8%／中小企業 15.8%／大企業 9.5% | **16%** |
| 売上高営業利益率 | 卸売業の中小企業 1.5%／飲食料品卸売業 1.1% | **1.25%**（飲食料品卸売業の実態値に近い水準） |

検算:

```
月商 4,000万円 × 粗利率 16%   = 粗利 640万円
粗利 640万円 − 固定費 590万円 = 営業利益 50万円  → 営業利益率 1.25%
年間の営業利益 ≒ 600万円
```

**この設定がゲームの緊張を数字から自動的に生み出す。** 取引先1社の焦げ付きが600万円なら、それだけで**1年分の利益が消える**。「1件の与信判断ミスが1年を無駄にする」という感覚は、演出ではなく収支構造から出てくる。

**固定費は毎年4月（第1・13・25ターン）に月+25万円ずつ上昇する。** 3年で+50万円になり、月商4,000万円を保つだけでは3年目に営業利益がほぼ消える。物価高・人件費上昇による倒産が実際に増えていること（付録B）を反映すると同時に、**「新規を全部断って守りに入る」という戦略を成立させないための仕掛け**でもある。

## 3. ゲームループ

### 3.1 時間の単位

1ターン = 1ヶ月。全36ターン。**2025年4月（第1ターン）〜 2028年3月（第36ターン）**。

開始月を2025年4月にしたのは、第10ターンが2026年1月、第24ターンが2027年3月になるからである。取適法の施行（2026年1月1日）と紙の手形・小切手の利用終了（2026年度末）を、どちらもゲーム期間内に踏ませる（§4.2、§5.9、§7.1）。

### 3.2 1ターンの流れ

```
┌─ ターン開始 ──────────────────────────────────────┐
│                                                          │
│  ① 引合いフェーズ                                       │
│     新規取引先の打診が 0〜3 社                           │
│                                                          │
│  ② 与信判断・条件交渉フェーズ            ┐               │
│     売るか／限度額をいくらにするか       │ 前半の主役    │
│     ＋ 保全条件を何と交換して取るか      │ 「売る前に    │
│                                          ┘   何を取るか」│
│  ③ 出荷・売上計上フェーズ                                │
│     限度額の範囲でのみ出荷 → 売掛金が発生                │
│                                                          │
│  ④ 入金フェーズ                                          │
│     支払条件に従って現金化／遅延判定（§6.9）             │
│                                                          │
│  ⑤ アクションフェーズ（枠: 初期3件）    ┐               │
│     調査・保全交渉・価格転嫁・回収を     │ 後半の主役   │
│     すべてこの共通枠から選ぶ             │ 「限られた   │
│     （§6.7、§6.8）                      ┘   手数で誰を  │
│                                              優先するか」│
│  ⑥ 月次コストフェーズ                                    │
│     仕入代金・固定費・実費・借入返済を支払                │
│     ★ 現金がマイナス → ゲームオーバー（黒字倒産）        │
│                                                          │
│  ⑦ イベントフェーズ                                      │
│     信用情報の変化／法令施行／仕入価格／発注減少          │
│                                                          │
└─ ターン終了 ─────────────────────────────────────┘
```

②と⑤が対になっているのが骨格である。**⑤で使える手札は②で仕込んだものだけ**という因果を、フェーズの並びで表現する。

**⑤のアクション枠を共通にしたのが v3.0 の重要な変更点である。** 調査（登記確認・信用調査）も回収も保全交渉も同じ枠を消費するため、「全社を毎ターン調べる」ことができない。**誰を疑うかという判断**がここで生まれる。枠は従業員を増やすと拡張できる（§6.8）。

### 3.3 各フェーズの詳細

#### ① 引合いフェーズ

新規取引先の打診が 0〜3 社ランダムに発生する。各社の属性:

| 属性 | 内容 | 例 |
|---|---|---|
| 社名・業種 | 6業種のいずれか（§6.2） | 「有限会社みなと水産」／小売 |
| 希望取引額 | 月あたりの取引希望額 | 月210万円 |
| 支払条件 | 締め日・支払月・支払日・支払方法（§4.1） | 末締め翌月末払い・現金 |
| 信用スコア | 30〜75 の整数、または「スコアなし」 | 61 |
| 取引実績 | 新規／既存 | 新規 |
| 開示状況 | 決算書を出す／出さない | 出さない |
| 交渉余地 | **1〜3ポイント（隠しパラメータ）**（§6.3） | 2 |

決算書を出さない相手・設立が新しい相手は「スコアなし」となる。スコアを知るには信用調査を依頼する（§6.8）。

#### ② 与信判断・条件交渉フェーズ

打診1社ごとに3択。既存取引先についても毎ターン「続ける／減らす／止める」を選べる。

| 選択肢 | 効果 | リスク |
|---|---|---|
| a. 掛で売る | 売上が立つ。限度額を自分で入力し、総与信枠から配分する（§4.4） | 焦げたら損失。取り戻せる額は⑤の手札次第 |
| b. 現金・前払いを要求 | リスクゼロ | **40%の確率で失注** |
| c. 断る | リスクゼロ | 売上が伸びない。断った累計額はエンディングで開示される（§8.4） |

aを選ぶとき、**同時に保全条件を交渉できる**（§6.3）。

#### ③ 出荷・売上計上フェーズ

自動処理。プレイヤーが設定した与信限度額を超える売掛残高は出荷不可となり、超過分の売上は立たない。

**限度額は「残高の上限」であって「月商の上限」ではない。** ここが最も誤解されるので、②の入力画面で月次の出荷可能額に換算して即時表示する（§9.3）。

#### ④ 入金フェーズ

支払条件に従って売掛金が現金化される。ここで遅延が発生する（判定は §6.9）。手形は支払日に受け取り、手形サイトの経過後に現金化される。

#### ⑤ アクションフェーズ

共通枠（初期3件／ターン）から選ぶ。対象は回収（§6.7）とその他（§6.8）のすべて。**やりたいことすべてはできない。**

#### ⑥ 月次コストフェーズ

| 項目 | 計算 |
|---|---|
| 仕入代金 | 仕入方針に応じた発注額（§6.5）。基準は売上 × 84%（＝粗利率16%の裏返し）。支払は翌月末 |
| 固定費 | 月590万円から毎年+25万円（§2.4） |
| 実費 | ⑤で実行したアクションの費用（内容証明の郵送料、公正証書の作成費用、弁護士費用、調査費用） |
| 借入の返済・利息 | 借入をしている場合 |

**このフェーズで現金がマイナスになったらゲームオーバー**。損益計算書が黒字でも容赦なく倒産する。

#### ⑦ イベントフェーズ

§7 の表から発生。固定イベントと抽選イベントがある。

### 3.4 勝敗条件

**評価の軸は「儲けた額」ではなく「事故を起こさなかったこと」に置く。** 薄利の卸売業では3年で自己資本を大きく増やすことが構造的にできない（§2.4）ので、金額目標にすると「達成不可能」か「運任せ」のどちらかになる。

指標は**焦げ付きによる純損失**（＝回収不能額から回収アクションで取り戻した額を引いたもの）。回収の努力が数字に反映されるため、⑤のアクションフェーズが評価に直結する。

しきい値は**金額と率の両方**で判定する。率だけでは「売上を膨らませて分母を太らせる」抜け道が残るためである。

| 結果 | 条件 |
|---|---|
| 勝利（優）「無事故経営」 | 36ターン生存 かつ 焦げ付き純損失が **1,500万円以内 かつ 累計売上の1.0%以内** |
| 勝利（良）「堅実経営」 | 36ターン生存 かつ 焦げ付き純損失が **3,500万円以内 かつ 累計売上の2.5%以内** |
| 生存 | 36ターン生存（損失率は問わない） |
| 敗北 | 現金がマイナスになった時点で即終了。「黒字倒産だったか／赤字倒産だったか」を最終画面で判定して表示する |

**しきい値の根拠**: 累計売上は36ヶ月×月商4,000万円で約14.4億円。1.0% = 1,440万円なので、金額側の1,500万円とほぼ一致する。最大の焦げ付き源である主要取引先（残高2,800万円）は、保全を取っていれば回収率70〜95%で純損失140〜840万円に収まり、取っていなければ2,520〜2,800万円になる（§6.9）。**保全を取ったか取らなかったかが、そのまま優・良の分かれ目になる**ように設計している。

#### 「優」への道筋（読み手が自力で気付けないため明記する）

主要取引先（東部フード）は既存取引先なので、交渉余地は正常時で**1**しかない（§2.3）。物的担保（3pt）を取るには、**対価を3つ全部差し出す必要がある**。

```
余地 1 ＋ 売価1%引き(+1) ＋ サイト30日延長(+1) ＋ 取引額20%減(+1) = 4  → 3pt の要求が通る
```

代償は重い。売上の31%を占める主力に対して値引きし、入金を1ヶ月遅らせ、数量を2割削る。**短期的には確実に苦しくなる。** だが第30ターンにこの会社は法的整理に入るので、担保があれば純損失は140〜840万円で収まり、なければ2,520〜2,800万円で「良」すら届かない。

これが「優」を狙うプレイヤーの山場である。**主力への大幅な譲歩を、10ターン以上先の事故のために飲めるか**という決断になる。しかも第20ターンのスコア急落を待ってからでは余地が1に固定され、対価3つでも4止まりで間に合うが、遅延が始まる第28ターン以降は余地0で何も取れない。

自己資本と現金残高は最終画面に必ず表示するが、**勝敗の判定には使わない**。「利益は出したが事故も出した」プレイヤーより「利益は薄いが事故はゼロ」のプレイヤーを高く評価する。これがこのゲームの価値観であり、与信管理という仕事の価値観でもある。

**解説カードの獲得数は勝利条件に含めない。** §8.1 のとおりカードは失敗時の発火を重視しているため、無事故で終えたプレイヤーほどカードが集まらない。無事故を最高評価とすることと矛盾する。カードは独立した達成として表示する。

## 4. 学ばせたい商習慣

公知の一般知識として記述する。ゲーム内では解説カード（§8）で提示する。

### 4.1 締め日・支払月・支払日と「支払サイト」

日本の企業間の掛取引では、支払条件を「**いつまでの取引分を／いつ払うか**」の組み合わせで表す。

| 要素 | 意味 | 選択肢の例 |
|---|---|---|
| 締め日 | いつまでの取引分を1回分としてまとめるか | 末日、20日、25日、10日 |
| 支払月 | 締めた分を何ヶ月後に払うか | 当月、翌月、翌々月 |
| 支払日 | その月の何日に払うか | 末日、5日、10日、25日 |

実務では次のように言う。

> 「**末締め翌月末払い**」＝ 月末までの取引分を、翌月の末日に払う

**支払サイト**とは、売った日から入金までの日数の目安である。実務では**1ヶ月を30日として概算する**慣行がある。

```
支払サイト（日） = (30 − 締め日) + (支払月の繰り越し月数 × 30) + 支払日
                      ↑ 締めまでの待ち     ↑ 何ヶ月後か        ↑ その月の何日か
```

| 条件 | 計算 | サイト |
|---|---|---|
| 末締め翌月末払い | (30−30) + (1×30) + 30 | 60日 |
| 20日締め翌月10日払い | (30−20) + (1×30) + 10 | 50日 |
| 末締め翌々月末払い | (30−30) + (2×30) + 30 | 90日 |

#### 成立しない組み合わせ（ガード条件）

式は無効な組み合わせでも数値を返してしまうため、**式より先にガード条件を判定する**。実装ではこの順序を守ること。

| ガード条件 | 判定 | 例 |
|---|---|---|
| 支払月＝当月 かつ 支払日 < 締め日 | **成立しない**（締める前に払うことになる） | 末締め・当月20日払い／20日締め・当月10日払い |
| 支払月＝当月 かつ 支払日＝締め日 | 成立しない（同日締め同日払い） | 20日締め・当月20日払い |
| 支払月＝当月 かつ 支払日 > 締め日 | 成立する。サイト＝支払日 − 締め日 | 20日締め・当月末払い（10日サイト） |

「末締め・当月末払い」は締め日と支払日が同じ末日なので、上表の2行目に該当して成立しない。ゲームでこの組み合わせを選ぼうとしたら警告を出し、解説カードを1枚渡す。

#### 数え方には別解がある（教材として明示すべき点）

本書は支払サイトを「**取引日から入金まで**」で数え、末締め翌月末払いを60日としている。一方、実務では「**締め日から支払日まで**」を数えて同じ条件を「30日サイト」と呼ぶ用法も広く使われる。

手形サイト60日超が行政指導の対象になるという話（§5.11）と並べると混乱しやすいため、カード内で「本ゲームは取引日起点で数える。締め日起点で数える言い方もある」と明示する。教材としてここを曖昧にしてはいけない。

### 4.2 支払方法と手形サイト

| 支払方法 | 特徴 |
|---|---|
| 現金（振込・口座振替を含む） | 支払日に現金が入る |
| 手形 | 支払日に手形（または電子記録債権）を受け取り、**さらに手形サイトの日数が経ってから**現金になる |
| 一部手形 | 一部を現金、残りを手形で払う |

手形の場合、**実質のサイト = 支払サイト + 手形サイト**。例: 末締め翌月末払い（60日）＋手形サイト60日 = **実質120日**。売ってから4ヶ月現金が入らない。

これが本ゲームで黒字倒産を起こす主要因である。手形は割引（銀行に買い取ってもらう）で早期に現金化できるが、割引料が費用になる（§6.8）。

#### 手形は制度として終わりに向かっている ―― 二段階で効く

手形を前提にした資金繰りは、ゲーム期間中に**二度**打撃を受ける。混同しやすいので区別して扱う。

| 時期 | 何が起きるか | 適用範囲 |
|---|---|---|
| 2026年1月1日<br>（第10ターン） | 取適法の施行により、**委託取引の代金**を手形で払うことが禁止される（§5.9） | 製造委託・修理委託・情報成果物作成委託・役務提供委託・**特定運送委託**。**単純な物品の売買は対象外** |
| 2026年度末＝2027年3月末<br>（第24ターン） | 金融界の自主行動計画により、**紙の約束手形・小切手の利用が終了**する。2027年度初から電子交換所での交換も廃止される | 手形・小切手そのもの。取引類型を問わない |

**卸売業の通常の商品売買は取適法の対象外**なので、2026年1月の施行だけでは受取手形は消えない。消えるのは、プレイヤーが配送や加工を外注する場面（§5.10）と、大手小売のプライベートブランド商品の製造を受託する場面である。

一般の販売先から受け取る手形が使えなくなるのは**第24ターンの紙の手形・小切手の利用終了**のほうである。プレイヤーは電子記録債権（でんさい）などへの切り替え交渉を迫られ、応じない取引先が第25ターン以降に毎ターン抽選で現れる（§7.2）。

なお2026年度末の利用終了は義務ではなく、罰則も設けられていない。ただし銀行が交換を取り扱わなくなるため実務上は使えなくなる。この「罰則はないが実務上できなくなる」という制度変更のかたちも、カードで扱う価値がある。

### 4.3 手形ジャンプ ―― 最重要の危険信号

**手形ジャンプ**とは、取引先が「手形の支払期日を延ばしてほしい」と言ってくることである。資金が回っていない明確な兆候であり、応じるかどうかは重い判断になる。

- 断れば取引先が不渡り（手形の決済不能）を出して倒産しかねない
- 応じれば回収がさらに遅れ、傷が深くなる

第23ターンに必ず発生させ、3択を出す。

1. 応諾する（回収は2ターン遅れる。相手は生き延びるが、次のターンで再度要請してくる確率が高い）
2. 断る（相手は3ターン以内に法的整理に入る確率が高い。回収は⑤の手札次第）
3. **追加の担保・連帯保証人を条件に応諾する**（最も有利）

3が本ゲームの狙いである。この時点で交渉余地は1に縮んでいる（§6.3）ので、要求ポイント3の連帯保証は素のままでは通らない。**対価を3つ全部差し出せば（値引き1%＋サイト30日延長＋取引額20%減）余地は4になり、通る。**

つまり「取れるが、非常に高い」。**危険信号が出ている相手に、値引きとサイト延長と数量減を同時に飲ませることの意味**を考える場面になる。相手はすでに資金が苦しいのに、こちらは支払いをさらに遅らせろと言っているのだから。ここまでして守る相手なのかを判断させたい。

これを体験させてから、「では取引開始時なら余地2〜3で済んだのに」という気付きに繋げる（§4.7）。

### 4.4 与信限度額と総与信枠 ―― v3.0 の中心的な変更

**与信限度額**とは「この取引先には、代金未回収の状態を最大いくらまで許すか」という上限である。決め方の原則は次の一言に尽きる。

> **安全限度と必要限度の、小さいほうを採る**

- **必要限度**: 取引を成立させるのに必要な額。これを下回ると商売にならない
- **安全限度**: 自社の体力から見て、焦げても耐えられる額

#### 必要限度の算式

```
必要限度 = 月間販売額 × 売掛期間（月数）
         + 月間販売額 × 手形などによる回収割合 × 手形期間（月数）
```

**具体例**: 月商300万円、末締め翌月末払い（売掛期間2ヶ月）、うち半分が手形サイト3ヶ月なら

```
300万 × 2 + 300万 × 0.5 × 3 = 600万 + 450万 = 1,050万円
```

#### 安全限度 ―― 自己資本比の目安は、そのままでは中堅企業に使えない

与信管理の教科書には、格付ごとの上限を自己資本比で決める方法が載っている（最上位10%／上位6%／中位4%／下位2%／要注意1%／不可0%）。

**しかしこの指標を本ゲームの会社にそのまま当てると、商売が成立しない。** 自己資本5,000万円の中位4%は1社200万円。14社に配分しても総額2,800万円で、サイト2ヶ月なら**月商1,400万円しか売れない**。固定費590万円に対して粗利は224万円で、即座に赤字である。実際の売掛残高は8,000万円（自己資本の160%）ある。

これは指標が間違っているのではなく、**自己資本比の目安が、自己資本が大きく取引先数も多い企業を前提にしている**ためである。買掛金で仕入を回す卸売業では、売掛残高が自己資本を超えるのが普通である。

**この矛盾自体を教材にする。** ゲームでは自己資本比の目安を参考値として表示しつつ、実際の運用は次の総枠配分モデルで行う。「教科書の目安を素朴に当てると商売が止まる理由」のカードを、プレイヤーが目安を超えて入力した最初のタイミングで出す。

#### 総与信枠モデル（本ゲームの運用ルール）

```
総与信枠 = 自己資本 × 2.0倍   （初期: 5,000万 × 2.0 = 1億円）
```

**判定は「各社の与信限度額の合計」で行う（売掛残高ではない）。** 限度額の合計が総枠を超える設定はできない。残高は限度額以下に必ず収まるので、これで残高も自動的に枠内に入る。

残高ベースで判定すると、全社の限度額を上限まで設定しても総枠を超えられてしまい、**「配分がゼロサム」という設計の狙いが崩れる**。実務でも枠管理は限度額の合計で行う。

1社あたりの上限は、**総枠に対する比率**で格付別に決める。

| 格付 | 信用スコア | 1社あたり上限（総枠比） | 初期の金額 |
|---|---|---|---|
| 最上位 | 70以上 | 20% | 2,000万円 |
| 上位 | 62〜69 | 14% | 1,400万円 |
| 中位 | 54〜61 | 8% | 800万円 |
| 下位 | 46〜53 | 4% | 400万円 |
| 要注意 | 45以下 | 2% | 200万円 |
| 格付なし | スコアなし | 2% | 200万円 |

**総枠は有限な資源であり、配分がゼロサムになる。** 新規1社を取るには既存を削るしかない。これによって毎ターン必ずトレードオフが発生する。初期状態では総枠の80%が既に埋まっているため（§2.3）、最初のターンから枠の圧迫を感じる。

総枠は自己資本に連動するので、利益を出せば枠が増える。**「稼ぐと売れる量が増える」という成長実感**が、薄利のゲームに前向きな手応えを与える。

### 4.5 取引シェアの罠

特定の1社への売上シェアが高くなりすぎると、**その会社の経営が傾いたときに取引を縮小できなくなる**。縮小すればその会社が潰れ、潰れれば自社の債権も焦げるからである。結果、「支えるために売り続ける、しかし入金は遅れる」という悪循環に入る。

初期取引先の1社が売上35%・残高2,800万円で、格付上位の上限1,400万円を超えている（§2.3）。第20ターンでこの会社の信用スコアが急落し、第30ターンで法的整理に入る。プレイヤーは「切る／支え続ける／保全条件を追加交渉する」の判断を迫られるが、**スコアが落ちた後では交渉余地が縮んでいる**（§6.3）。

### 4.6 危険信号と、決算書が手に入らないという現実

取引先が「支払サイトを延ばしてほしい」「手形に変えてほしい」と言い出したら、資金が苦しいという申告に近い。ゲームではこの申し出をイベント化し、応じると以降の遅延確率が1.5倍になる（§6.9）。

同様の危険信号:

- 支払期日の延期要請、手形ジャンプの要請
- 給与の遅配、従業員の退職が急に増える
- 他の取引先から「あの会社、支払いが遅いらしい」という噂
- **競合が急に撤退した**（自社だけが売っている状態は、他社が危険を察知した結果かもしれない）

そして与信管理の教科書は「決算書を分析せよ」と書くが、実務では**取引関係で弱い立場だと提出を求めにくく、中小企業は調査会社にも非公開の会社が多い**。入手できても年1回・期末後数ヶ月でようやく出てくるので、**手に入った時点で既に過去の情報**である。

ゲームでは打診してくる取引先の約3割を「決算書を出さない」に設定する。この相手は「スコアなし」となり、格付なし＝1社上限が総枠の2%に制限される（§4.4）。**決算書が出ない相手には大きく売れない**という構造で表現する。

### 4.7 債権保全は取引開始時に決まる ―― 本ゲームの中心思想

回収の手段は、焦げてから考えるものではない。**取引を始めるときに何を取ったかで、後にできることが決まる**。

| 取引開始時に取れるもの | 焦げた後に効くこと |
|---|---|
| 取引基本契約書の期限の利益喪失条項 | 遅延時に残額を一括請求できる |
| 所有権留保の合意 | 代金完済まで所有権を留保し、引き揚げやすくする |
| 公正証書による債務承認弁済契約 | **裁判をせずに差押えに進める**（執行力） |
| 物的担保（不動産の抵当権、預金の質権など） | 優先して回収できる |
| 連帯保証人（代表者個人など） | 会社が払えなくても個人に請求できる |

いずれも**取引開始後の追加は極めて難しい**。相手の協力が必要であり、危険信号が出た後はまず応じてもらえない。ゲームでは交渉余地というパラメータでこれを表現する（§6.3）。

中盤以降、必ず焦げる取引先が出る。そのときに**保全を取っていた取引先とそうでない取引先の結末が明確に分かれる**（回収率で70〜95%対0〜10%、§6.9）。これが最も強い学習体験になる。

### 4.8 卸売業が実際に潰れる理由

公開統計と公表事例から調べた失敗要因を、ゲームのどの仕組みで表現するかに対応させる。統計の数値と調査の詳細は**付録B**に置いた。

| # | 潰れる理由 | ゲームでの表現 |
|---|---|---|

| 2 | 回収サイトと支払サイトのズレ | 資金繰り画面の3ターン先予測（§9.4）。黒字倒産の主要因 |

| 5 | 与信管理の甘さ | 与信限度額の自己入力（§6.4）と保全交渉（§6.3） |

### 4.9 取り込み詐欺（パクリ屋）

**取り込み詐欺**とは、代金後払いで商品を注文し、商品を受け取っておきながら代金を払わずに消える手口である。実行者は俗に「パクリ屋」と呼ばれる。

#### 手口の型

1. **助走**: 最初は小口の取引を何度も繰り返し、毎回きちんと支払って信用させる
2. **本番**: 頃合いを見て取引の規模を大きくし、あわせて**支払サイトの長い決済手段**を要求する。**このとき与信限度額の引き上げを明示的に求めてくる**
3. **消滅**: 納品を受けた後に代金を払わず、会社ごと姿を消す

狙われるのは**換金性の高い商品**である。米や肉などの食品、印刷用トナー、パソコンやタブレットが典型例として挙げられる。**食品卸を舞台にした本ゲームは、この手口の標的そのもの**である。

器として使われるのは、多くの場合**買い取られた休眠会社**である。商号・本店所在地・事業目的・役員を書き換えて、新しく設立された会社のように見せかける。

#### 商業登記から読める危険信号

- 事業目的に、**相互にまったく関係のない事業**が多数並んでいる
- **本店所在地が短期間に何度も移転**している
- 商号の変更歴がある、役員が最近まとめて入れ替わっている
- 設立年は古いのに、事業内容と現在の商号が噛み合わない（休眠会社の買収の痕跡）

#### なぜ回収が効かないのか

相手は資産を残さずに消えるため、督促しても届かず、差押えの対象もない。担保も連帯保証人も取れていないのが通例である。**相手が消えてしまう類型では回収法務のすべてが空振りする**（同じく取り返せない類型として §4.10 の架空循環取引がある。あちらは相手は存在するが債権が架空である）。対処は予防しかない。

#### ゲームでの表現

| 時期 | 起きること |
|---|---|
| 第7ターン±4 | 小口（月40万円）だが**毎回きっちり期日に払う**新規取引先が現れる。格付は下位で、上限400万円 |
| 以降 | 遅延を一度も起こさない |
| 第21ターン±4 | 同社が「月2,000万円の大口注文」を求め、**あわせて与信限度額を2,000万円に引き上げてほしいと要求する** |

**限度額の引き上げはプレイヤーの能動的な判断である。** 引き上げなければ出荷は限度額で止まる（§3.3③）ので、詐欺は成立しない。この点を設計書に明記しておくのは、実装者が「詐欺イベントでは限度額を無視する」という例外処理を書いてしまうのを防ぐためである。**理不尽な罠ではなく、プレイヤーが自分で枠を開けた結果**にすること。

手がかりは調べれば出る。**登記を確認する**（数千円・アクション枠1）で「事業目的が雑多」「本店が2年で3回移転」が判明し、**信用調査を依頼する**（数万円・アクション枠1）で「休眠会社の買収」まで判明する。

調べずに引き上げて出荷すると全損し、回収画面（§9.5）は全項目がグレーアウトする。**「相手が存在しないため、どの手段も使えません」**と表示して解説カードを渡す。

断った場合は何も起きない。正解を選んだことはエンディング（§8.4）で「回避した損失」として金額で示す。**何も起きなかったことが成果である**という感覚も、与信管理の理解として重要である。

### 4.10 架空循環取引

**架空循環取引**とは、複数の会社が実際には物やサービスのやり取りをしないまま、形式上の売買を繰り返して売上を膨らませる不正である。A社がB社に売り、B社がC社に売り、C社が再びA社に売るという形で伝票だけが回る。

#### 卸売業が巻き込まれる構造

架空取引には、当事者間で売買を往復させる型と、**取引の間に第三者を介入させる型**がある。後者では、介入させた第三者に**手形払いなどの金融機能を担わせる**ことが多い。そして最後に、その第三者の不良債権が膨らむ。

卸売業はこの「第三者」に選ばれやすい。**伝票を通すだけで口銭（手数料）が入る**という誘い方をされるからである。物を仕入れて売るのが本業なので、話としても自然に聞こえてしまう。

#### 公表されている事例

水産物の卸売を行う会社が、2023年に複数の取引先との架空取引を行っていたことが発覚した事例がある。A社から仕入れた水産物をB社へ販売し、B社が再びA社へ販売するという循環を繰り返していた。**実際の商品はA社の倉庫から動いていなかった**とされる。

#### 見抜き方

- **商品が実際に動いているか**（現物と、その移動を確認する）
- 自社がその取引に介在する**経済合理性があるか**（なぜ自社を通す必要があるのか）
- 利益率が不自然に安定していないか
- 取引の実態が「伝票と請求書のやり取りだけ」になっていないか

#### 法的リスク

架空の売上を計上する行為は**粉飾決算の一種**である。上場会社であれば、開示書類の虚偽記載として金融商品取引法違反にあたる。加担すれば、詐欺や共同不法行為としての責任を問われうる。**知らずに巻き込まれた場合でも、膨らんだ売掛金は自社が負う**。

#### ゲームでの表現

第13ターン±4に誘いが来る。「伝票を通すだけで口銭3%。1件5,000万円、月1回」。**粗利率16%の商売にとって、これは異常に良い条件である。**

- **乗る**: 4ターンにわたって利益が出る（気持ちよく儲かる）。その後、連鎖が破綻して売掛金が回収不能になる。加えて信用が失墜し、他の取引先の交渉余地が全社で1減る
- **現物を確認する**（アクション枠1）: 「商品は倉庫から動いていない」と判明し、正体が分かる
- **断る**: 何も起きない

誘い文句を「儲かる話」として魅力的に書くことが重要である。**警戒すべきだと分かる書き方をしてはいけない**。実際の誘いも魅力的に聞こえるからこそ人は乗る。

## 5. 学ばせたい関連法

### 5.1 前提 ―― 掛売りとは「代金を後で受け取る約束」を持つこと

掛売り（信用取引）をすると、売り手は**売掛金という債権**を持つ。物は渡したが金はまだ受け取っていない状態である。この債権は財産なので、譲れる（§5.3）、相殺できる（§5.4）、担保にできる、そして**放っておくと消える**（§5.2）。

チュートリアルではこの一点だけを押さえる。以降の法令はすべてこの前提の上に乗る。

### 5.2 消滅時効 ―― 民法166条・150条・152条

- **民法166条**: 債権は、権利を行使できることを知った時から**5年**（または行使できる時から10年）で消滅する
- **民法150条**: **催告**をすると、そのときから**6ヶ月間**は時効が完成しない（完成猶予）
- **民法152条**: 相手が債務を**承認**すると、時効は**更新**される（振り出しに戻る）

**「催告は延命、承認は更新」**と覚えさせる。カードのタイトルもこの文にする。

初期状態に「先代が放置した売掛金430万円」を持たせ、**第14ターンに時効を迎える**。それまでに催告・債務承認・法的手続のいずれかを打てば救えるが、放置すれば消える。

> 注: 36ターン＝3年では新規の債権が5年の時効を迎えることはない。時効を体験させるために、先代からの債権という形で時間軸を借りている。この演出であることをカード内に明記する。

### 5.3 内容証明郵便と債権譲渡の対抗要件

**内容証明郵便**は、いつ・誰が・誰に・どんな内容の文書を送ったかを郵便局が証明する仕組みである。それ自体に強制力はないが、催告の事実と日付を証明でき（§5.2 の完成猶予の根拠になる）、期限の利益喪失通知を確実に届けられる。

ゲームでは「督促の電話」と「内容証明の送付」を別のアクションにする。電話は無料だが記録が残らず、内容証明は費用がかかるが時効の猶予が付く。**この差が理解できると法務の基礎が入る。**

**債権譲渡**（民法466条・467条）では、譲り受けたことを主張するのに**対抗要件**が必要である。

| 誰に対して主張するか | 必要なもの |
|---|---|
| 債務者（払う側）に対して | 譲渡人からの**通知**、または債務者の**承諾** |
| 第三者（他の債権者など）に対して | **確定日付のある証書**による通知・承諾、または**債権譲渡登記** |

ゲームでは**買取型ファクタリング**（自社の売掛債権を売って早期に現金化する。手数料5〜15%）で扱う。自社が譲渡人になる側なので、対抗要件は「通知・承諾」の形で登場する。

> 回収手段としての債権譲渡（焦げた取引先が第三者に持つ売掛債権を譲り受ける）は、**アクションとしては用意しない**。相手の販売先のデータ構造が必要になるうえ、対抗要件の学習はファクタリング側で足りるためである（付録A）。

ファクタリングを使うときに「これは債権の売買であって借入ではない」という法的性質をカードで示す。粗利率16%に対して手数料10%は**粗利の6割超を吹き飛ばす**ので、この選択は重い。

### 5.4 相殺 ―― 民法505条

自社が相手に対して債務（買掛金など）を持っている場合、**売掛金と買掛金を差し引きできる**。相手の同意は不要で、意思表示だけで成立する。

回収手段として極めて強力である。相手が破産寸前でも、相殺できる範囲は確実に回収できる。ただし破産手続に入った後の相殺には制限がある（破産法71条・72条）ため、**早く気付いて実行するほど有利**である。

**本ゲームでは相殺を運任せにしない。** プレイヤーは仕入先を選べる（§6.5）。危ない売り先から仕入れれば、焦げたときに買掛金の範囲を確実に回収できる。仕入価格は3%高くなるので、**割高な仕入は保険料である**という理解が生まれる。相殺の学びを「気付き」から「作る行為」に格上げする。

### 5.5 動産売買先取特権 ―― 民法311条・321条・304条

**自分が売った動産の代金**については、その動産（または転売されたときの代金債権）から優先して回収できる法定の担保権がある。契約書に書いていなくても法律上当然に発生する。

ただし実務上のハードルが高い。その動産が**まだ相手のところにあり、特定できる**必要があり（転売・加工・混和されると難しい）、転売されていれば転売代金債権を差し押さえる形になる（相手の販売先を把握している必要がある）。

食品卸を舞台にしたのはこれを扱いたいからでもある。**納品したものが在庫として残っているうちに動けば回収できる**。1ターン遅れると売り切られて消える。第27ターンに、納品直後に取引先が事業停止するイベントを置き、**この手段が間に合う唯一の機会**にする。

### 5.6 公正証書と債務承認弁済契約 ―― 執行力を先に手に入れる

通常、相手が払わないときに強制的に回収するには、裁判を経て判決（債務名義）を得る必要がある。時間も費用もかかる。

しかし、**執行力のある公正証書**（民事執行法22条5号）があれば、裁判を飛ばして差押えに進める。作成には相手の協力が必要なので、**取引開始時か、まだ関係が良好なうちにしか取れない**。

ゲームでは、公正証書を持っている取引先が焦げたとき、回収画面に「差押えを申し立てる」が即座に現れる。持っていない取引先では、まず「支払督促・訴訟」に2〜4ターンかけなければならない。**この差が勝敗を分ける局面を必ず1回作る**（第30ターン）。

### 5.7 人的担保・物的担保と根保証の極度額 ―― 民法465条の2

回収を確実にする手段は、大きく2つに分かれる。**人的担保**（連帯保証人を取る）と**物的担保**（抵当権、質権、譲渡担保など）。

2020年4月施行の民法改正で、**個人が根保証（継続的な取引から生じる不特定の債務の保証）をする場合、極度額（上限額）を定めなければ保証契約は無効**とされた。

ゲームでは、連帯保証人を取るときに極度額を入力させる。**極度額を空欄のまま進めても警告を出さずに通す。** 焦げて請求した瞬間に無効になって初めて気付く。手痛いが一度で覚える。

> 注: ここで扱うのは取引先の代表者などから取る**人的担保としての保証**である。保証会社が提供する売掛保証サービスとは別物であり、本ゲームは後者を扱わない（§6.1）。カード内でこの区別を明記する。

### 5.8 破産・民事再生と配当順位

取引先が法的整理に入ると、個別の回収は止まる。売掛金は他の債権者と並んで配当を待つ立場になる。

配当には順位がある。おおまかには、担保権者（別除権）→ 財団債権・優先的破産債権（租税、一定範囲の労働債権）→ 一般の破産債権（売掛金はここ）である。**一般の破産債権に回ってくる財産は、多くの場合ほとんど残らない。**

- **破産**: 会社は消滅する。債権届出をして配当を待つ
- **民事再生**: 会社は存続する。再生計画で債権が大幅に減額され、残りが分割で支払われる

ゲームでは第30ターンの主要取引先の法的整理を、**70%の確率で破産／30%で民事再生**に分岐させる。結果は保全状況で決まる（§6.9）。民事再生を単独イベントにしないのは、プレイヤーの選択肢が「再生計画に同意する／しない」しかなく、判断として薄いためである。

### 5.9 取適法（旧下請法）―― 2026年1月1日施行

下請法（下請代金支払遅延等防止法）が改正され、2026年1月1日から**中小受託取引適正化法（略称: 取適法）**となった。

| 変更点 | 内容 |
|---|---|
| 名称 | 「下請法」→「取適法」。「下請」という語自体も見直された |
| 適用範囲（規模） | 従来の資本金基準に加え、**従業員数基準が導入**（製造委託等では300人以下、情報成果物作成・役務提供委託では100人以下）。フリーランスなど幅広い受託者が保護対象になる |
| **適用範囲（取引類型）** | 従来の製造委託・修理委託・情報成果物作成委託・役務提供委託に加え、**特定運送委託（発荷主が運送事業者に物品の運送を委託する取引）が新たに追加された** |
| **手形払いの禁止** | 支払手段として手形を用いることが禁止された。電子記録債権やファクタリングも、支払期日に手数料込みの全額を受け取れない形なら禁止 |
| 価格の一方的決定の禁止 | 受託者が協議を求めたのに一方的に代金を決めることが禁止（価格据置取引への対応） |

**適用範囲の理解が最重要である。** 対象は上記の**委託取引**であり、単純な物品の売買は含まれない。卸売業が商品を仕入れて売る通常の取引はこの法律の対象外になることが多い。

**一方、特定運送委託の追加は本ゲームに直撃する。** プレイヤーは配送を外注しているので、**自社が「発荷主」として法の対象になる**。第10ターンの施行イベントで、次の3つの立場を同時に経験させる。

| プレイヤーの立場 | 何が起きるか |
|---|---|
| **発荷主として配送を委託している** | 運送事業者への支払が新たに法の対象になる。手形払いができなくなり、60日ルール（§5.10）も効く。**守る義務を負う** |
| **受託する側**（大手小売のプライベートブランド商品の製造を受託） | 相手から手形で払われていた分が現金払いに変わる。**保護される** |
| **単純に売っている分**（通常の卸売） | **何も変わらない**。ここが引っかけである |

3つ目が学習の要点である。「法改正で手形がなくなった」と早合点したプレイヤーは、通常の販売先から相変わらず手形で払われることに気付く。**同じ会社の中に、法律が効く取引と効かない取引が混在する**という感覚を持ってもらう。

### 5.10 支払期日の60日ルールと遅延利息

取適法では、**受領日から60日以内**に代金を支払う義務がある。違反すると**年14.6%**の遅延利息が発生する。

**起算点は取引の種類で言い方が変わる。** 物品の製造委託などでは「物品等を受領した日」、役務提供委託（配送の委託を含む）では「**役務の提供を受けた日**」が起算点になる。第10ターンで追加される特定運送委託は後者にあたるため、教材としてここを取り違えてはいけない。

ゲームでは、プレイヤーが配送・加工の外注先に支払う立場でこれが効く（§5.9 の特定運送委託の追加により、第10ターン以降は運送委託も対象）。資金繰りが苦しいときに「外注費の支払を来月に延ばす」という選択肢を出し、選ぶと遅延利息と行政指導リスクが発生する。**保護される側と保護する側の両方を経験させる**のがこの仕掛けの目的。

### 5.11 手形サイト60日超の指導 ―― 2024年11月からの運用

2024年11月1日から、手形を代金の支払に用いる場合、**サイトが60日を超える手形は「割引困難な手形」として行政指導の対象**になった。従来は業種によって90日・120日が許容されていた。

第5ターンに手形サイト120日を提示してくる取引先を出す。プレイヤーは「60日に短縮するよう交渉する」を選べる（成功確率60%）。この交渉に法的な裏付けがあることをカードで示す。

### 5.12 商業登記 ―― 相手が実在するかを確かめる制度

会社の商号・本店所在地・事業目的・役員・設立年月日などは**商業登記**として公開されており、誰でも登記事項証明書を取得できる。相手の実在と沿革を確かめる、最も安価で確実な手段である。

登記は「今の姿」だけでなく**変更の履歴**を残す。ここに §4.9 で挙げた危険信号が現れる。

「**登記を確認する**」は数千円・アクション枠1で実行できる。信用調査（数万円・アクション枠1）より安く、支払能力は分からないが、**会社の来歴の不自然さは分かる**。この使い分けを学ばせたい。

### 5.13 インボイス制度と免税事業者

適格請求書（インボイス）がなければ仕入税額控除が取れない。**仕入先が免税事業者である場合、その分のコストを自社が負担することになる。**

ゲームでは仕入先選択（§6.5）でこの論点を出す。相殺の盾として魅力的な仕入先が免税事業者で、表示価格は安いが実質コストは高いというケースを作る。**「安い」の意味を確かめる習慣**を付けさせる。

### 5.14 貸倒損失の計上と税

回収不能が確定した売掛金は、貸倒損失として損金に計上できる。計上の要件と時期は税務上の論点であり、**いつ「回収不能」と判断したかの記録が根拠になる**。

**税は実効税率30%の1行モデルで扱う。**

```
納税額 = max(0, (年間営業利益 − 貸倒損失計上額)) × 30%
```

各年度末（第12・24・36ターン）の決算フェーズで、焦げた債権を「まだ回収を試みる／貸倒損失として計上する」の2択にする。計上すれば納税額が減って現金が残るが、回収を諦める意思表示になる。後で回収できた場合は益金として課税される。**回収を諦めるという判断にも会計上の意味がある**ことを扱う。

### 5.15 反社会的勢力の排除

反社会的勢力との関係が判明した場合、財務内容がどれほど良好でも取引はできない。

条件が非常に良い取引先を1社出す（罠プールの1種）。信用調査を依頼すると関係が判明する。**調査せずに売ってしまうと、後で重いペナルティイベントが発生する**（取引先の一部が離反し、月商が15%減る）。「調査は費用ではなく保険である」という判断を学ばせる。

なお、不正な取引に関わったときの法的責任（取り込み詐欺の相手方は詐欺罪、架空循環取引への加担は金融商品取引法違反や共同不法行為にあたりうる）は、**罪名を覚えさせることを目的にしない**ため、独立した節を設けずカード1枚に統合する。

### 5.16 本ゲームで扱わない法令

設計上の判断であり、重要でないという意味ではない。電子帳簿保存法、犯罪収益移転防止法、消費税の軽減税率、個人情報保護法、保険業法（売掛保証・取引信用保険を扱わないため）。

## 6. ゲームメカニクス詳細

再掲: **本章の数値はすべて本ゲームの設計値である。**

### 6.1 売掛保証サービスを登場させない理由（設計判断の記録）

初期の構想では、売掛保証サービスに加入して取引先ごとに保証を付ける仕組みを中核に置いていた。**これを外した。**実装時に「保証も入れたほうが親切では」と踏み込まれるのを防ぐため、理由を残しておく。

1. **学びたいことが商習慣と法令なら、保証の手続きは目的外である**。申込・審査・遅延報告・請求期限・打ち切りといったルールは特定のサービスの約款の話であり、それでいてルールの分量が最も多く、覚えるべきことを覆い隠す
2. **リスクを外部に移せると、与信判断そのものが消える**。「迷ったら保証を付ける」が常に正解になり、限度額や保全の判断が意味を失う
3. **回収法務を厚くする枠を作れる**。保証があると「焦げても戻ってくる」ので、内容証明・相殺・先取特権・公正証書を使う動機が弱くなる

リスクを外部に移す手段としては、買取型ファクタリング（§5.3）のみを残す。法的性質が明快で、手数料が高いため濫用されない。

### 6.2 取引先の業種とリスクプロファイル

| 業種 | 希望取引額 | 典型的な支払条件 | 実効サイト | **最上位格付でも売れる上限** | 月次遅延確率 | 回収法務との関係 |
|---|---|---|---|---|---|---|
| 小売（食品スーパー） | 月100〜300万 | 末締め翌月末払い・現金 | 2.0ヶ月 | 月1,000万 | 2.0% | 在庫が動くのが速く、先取特権が使いにくい |
| 飲食チェーン | 月50〜200万 | 末締め翌月20日払い・現金 | 1.67ヶ月 | 月1,198万 | **5.0%** | 消費されるので物が残らない |
| 建設・工事 | **月300〜1,500万** | 末締め翌々月末払い・手形 | **3.8ヶ月** | **月526万** ⚠ | 3.0% | 資材が現場に残る |
| 製造 | 月200〜800万 | 20日締め翌月末払い・一部手形 | 3.13ヶ月 | 月639万 | 1.5% | 加工されると先取特権が難しくなる |
| EC・通販 | 月30〜150万 | 末締め翌月末払い・現金 | 2.0ヶ月 | 月1,000万（ただし多くは格付なしで**月100万**） | 4.0% | 設立が新しく**スコアなしが多い**／在庫は追える |
| 医療・福祉 | 月30〜100万 | 末締め翌月末払い・現金 | 2.0ヶ月 | 月1,000万 | 1.0% | 公的な収入源が差押えの対象になり、見込みが立つ |

「最上位格付でも売れる上限」の列が本ゲーム固有の重要な事実である。**建設業は希望額が月1,500万まであるのに、最上位の格付でも月526万しか出荷できない。** 実効サイトが3.8ヶ月と長いため、同じ与信枠で売れる量が小売の半分になるからである。

これは制約ではなく**教材**である。「サイトが長い業種は、同じ枠で半分しか売れない」という因果を、希望額と上限の差として毎回見せる。建設業の大口案件は、枠を大量に食う割に売上が伸びない選択肢になる。

業種ごとに「焦げたときに使える手段」が変わるのが要点である。飲食に売った食材は消えるが、建設現場に納めた資材は残っている。

なお**相殺の可否は業種では決まらない**。プレイヤーが仕入先として選んだ相手かどうかだけで決まる（§5.4、§6.5）。

### 6.3 与信判断と保全の交渉 ―― 交渉余地モデル

保全条件の要求を「失注確率の加算」で表すと、期待値計算で機械的に解けてしまう。そこで**交渉余地モデル**を採る。

各取引先は**隠れた交渉余地（1〜3ポイント）**を持つ。保全要求にはポイントが設定されており、**要求の合計が余地以内なら確実に成立し、超えたら失注する**。

| 要求する保全 | ポイント |
|---|---|
| 期限の利益喪失条項 | 1 |
| 所有権留保 | 1 |
| 公正証書（債務承認弁済契約） | 2 |
| 物的担保 | 3 |
| 連帯保証人（極度額の入力が必須） | 3 |

#### 対価を差し出して余地を広げる

余地は交換で広げられる。**ここが判断の核心である。**

| 差し出すもの | 余地の増加 | 代償 |
|---|---|---|
| 売価を1%下げる | +1 | 粗利率が16%→15%になる。3年で効いてくる |
| 支払サイトを30日延ばす | +1 | 現金化が遠のく。資金繰りが悪化する |
| 取引額を20%減らす | +1 | 売上が減る |

これで判断が「確率の期待値」から「**何を差し出すか**」に変わり、機械的に解けなくなる。粗利16%の商売で1%の値引きは**粗利の6%を失う**ことに等しく、決して軽くない。

#### 余地は調べても幅までしか分からない

| 手段 | 分かること |
|---|---|
| **登記を確認する** | 余地の**下限**（「2以上」など） |
| **信用調査を依頼する** | 余地の**レンジ**（「2〜3」）。正確な値は分からない |

**正確な値を出さないのが要点である。** 決定論のモデル（余地以内なら確実に成立）に正確な情報を組み合わせると、「余地ちょうどまで要求する」が100%成功する確定最適手になってしまう。幅を残すことで判断が残る。

#### 調査の結果は翌ターンに出る

**調査を発注したターンには結果が出ない。翌ターンに判明する。** 引合いへの返答は当月中に必要なので、**「調べる時間がない相手に売るかどうか」**という判断が生まれる。継続取引の相手や、次回の増額に備えて調べておく相手には有効に働く。

これがなければ、アクション枠3で毎月の引合い（平均1.5社）を全社調査してから判断するのが常に最適になり、「誰を疑うか」の判断が消える。

#### 要求が1pt超えたときは対案が返る

要求合計が余地を**1pt**超えた場合は即失注ではなく、**相手が代替案を出してくる**（例: 公正証書2ptを求めたら「代表者の連名保証なら」と1ptの案が返る）。2pt以上超えたら失注する。

境界で1回だけ再交渉できる形にすることで、余地の推定に幅があっても意思決定が壊れない。

#### 余地は時間とともに縮む

| 状況 | 余地 |
|---|---|
| 新規取引の交渉時 | 初期値（1〜3） |
| 取引開始後・正常時 | 初期値 − 1 |
| 信用スコアが下落した後 | 1 に固定 |
| 遅延が発生した後 | 0（何も取れない） |
| 信用が失墜した後（架空循環取引に加担した場合など） | 全社で −1 |

**信用スコアが高い相手は交渉力も強い**ため、余地の初期値は低くなる（§6.9(e)）。安全な相手ほど保全が取れず、危険な相手ほど保全を求めるべきだが売りたくない、というねじれを作る。これは実務の感覚に近い。

### 6.4 与信限度額の入力

プレイヤーは取引先ごとに与信限度額を入力する。**限度額の合計が総与信枠（§4.4）を超えない範囲**、かつ格付別上限の範囲内でのみ設定できる。新規に枠を割り当てたいときは、既存の限度額を減らして空ける（§9.2 の「枠の遊び」列）。

**入力欄の直下に、月次の出荷可能額を即時換算して表示する。** これが本ゲームで最も重要なUIである。

**換算には手形分を含めた実効サイトを使う。** 必要限度の算式（§4.4）が手形を含めているのに換算式が含めなければ、最重要のUIが自ら教えている算式と違う数字を出すことになる。

```
実効サイト = 売掛期間（月数） + 手形回収割合 × 手形期間（月数）
月次の出荷可能額 = 限度額 ÷ 実効サイト
```

手形のある相手では**2行並べて表示する**。

```
限度額 700万円
  現金払いなら（2.3ヶ月）   → 月304万円まで出荷できます
  一部手形込み（3.1ヶ月）   → 月226万円まで出荷できます  ← 実際はこちら
                              （希望額 640万円の 35%）
```

**「手形を受けると、同じ枠で売れる量が3割減る」**という最も重要な因果が、この2行で見える。手形を受けるかどうかの判断が、資金繰りの話だけでなく**売上の話**でもあることが伝わる。

自己資本比の目安（§4.4）も参考値として併記し、超えた入力には警告を出すが**強制はしない**。

**「教科書の目安をそのまま当てると商売が止まる理由」のカードは、第1ターンの最初の限度額入力時に出す。** §4.4 の算術（自己資本比を素朴に当てると月商1,400万しか売れない）は第1ターンの時点で通る道であり、ここで先に見せておかないと総枠モデルの意味が理解できない。段階的開放（§3.5）で第1〜4ターンはサイトと限度額しか触らせないのだから、置く場所としても自然である。

### 6.5 仕入・在庫・仕入先の選択

#### 仕入方針

過剰在庫は卸売業の黒字倒産の主要因である（§4.8）。**在庫は現金が形を変えたもの**であり、売れなければ現金には戻らない。プレイヤーが操作するのは仕入方針の1項目だけで、品目管理はしない。

| 仕入方針 | 発注量 | 効果 | リスク |
|---|---|---|---|
| 受注仕入 | 受注分のみ | 在庫が寝ない。現金効率が最も良い | 突発の大口注文に応じられず**失注する** |
| 標準 | 受注見込 × 1.2 | バランス型 | — |
| 見込み仕入 | 受注見込 × 1.6 | 大口の引合いに即応できる | 売れ残りが現金を食う。**食品なので一部は廃棄になる** |

在庫は資金繰り画面（§9.4）に現金とは別枠で表示し、**この数字が大きいほど現金が少ない**という対応を見せる。仕入価格が高騰したときに見込み仕入をしていると、**高値の在庫を抱える**ことになる。

#### 仕入先の選択

**仕入先はプレイヤーが選ぶ。** これによって相殺（§5.4）を能動的に作れる。

| 仕入先の選び方 | 仕入価格 | 効果 |
|---|---|---|
| 通常の仕入先 | 標準 | — |
| **売り先を兼ねる相手から仕入れる** | +3% | 焦げたときに**買掛金の範囲を確実に回収できる**（相殺） |
| 免税事業者から仕入れる | **−8%（表示価格）** | 仕入税額控除が取れないため、**実質は約2%高い**（§5.13）。表示だけ見ると得に見える |

危ない売り先から割高に仕入れるのは、**保険料を払う行為**である。この理解が生まれると、相殺は運ではなく戦略になる。

### 6.6 遅延の発生と進行

遅延は段階的に悪化する。各段階でプレイヤーが打てる手が変わる。

```
  正常  ──→  遅延  ──→  長期遅延  ──→  法的整理／事業停止
              │           │                │
              │           │                └ 個別回収は停止。配当を待つ（§5.8）
              │           └ 一括請求が可能（期限の利益喪失条項があれば）
              │             他の債権者も動き始め、先取特権と相殺が間に合わなくなる
              └ 督促・催告のタイミング。まだ相手に払う意思がある可能性
```

| 段階 | 条件 | 起きること |
|---|---|---|
| 遅延 | 支払期日に入金がない | 通知が出る。回収アクションが選べる。交渉余地は0になる |
| 長期遅延 | 遅延が2ターン継続 | 信用スコアが大きく下がる。先取特権と相殺の成功率が下がる |
| 法的整理／事業停止 | 長期遅延から確率遷移（§6.9） | 個別回収が止まる。§5.8 の順位に従って結果が決まる |

**早く動くほど回収できる。** アクション枠は有限なので、どの債権を優先するかの判断が発生する。

### 6.7 回収アクション

各アクションは**回収率にボーナスを与える**（確率ではなく率で統一する。§6.9）。

| アクション | 前提 | 費用 | 回収率ボーナス | 副作用 |
|---|---|---|---|---|
| 電話・訪問で督促 | なし | 0円 | +5〜10pt | なし |
| 内容証明で催告 | なし | 数千円 | +10pt | **時効の完成猶予6ヶ月**。関係が悪化し取引再開は困難 |
| 支払計画を合意する | 相手に払う意思がある | 0円 | +15pt | **債務承認により時効が更新**。回収が長期化し、その間の倒産リスクを負う |
| 公正証書を作る | 相手の協力（交渉余地2以上） | 数万円 | — | 以後、裁判なしで差押えに進める。1ターン消費 |
| 相殺する | 相手が仕入先を兼ねる | 0円 | 買掛金の範囲を**100%回収**（§6.9(c) の別枠。基準回収率より先に確定する） | その範囲のみ。法的整理後は制限あり |
| 商品を引き揚げる | 相手の合意、または所有権留保 | 運送費 | +20〜40pt | 他の債権者との紛争リスク |
| 動産売買先取特権を行使 | 納品物が特定でき、まだ売られていない | 弁護士費用 | **+30pt** | **時間が経つと使えなくなる**。手続が煩雑 |
| 連帯保証人に請求 | 連帯保証人を取得済み | 0円 | —（**§6.9(c) の基準回収率40〜90%を発動させる**アクション。ボーナスではない） | **極度額未設定なら無効**。極度額でキャップされる |
| 担保を実行 | 物的担保を取得済み | 手続費用 | —（**§6.9(c) の基準回収率70〜95%を発動させる**アクション。ボーナスではない） | 手続に2ターン |
| 支払督促・訴訟 | なし | 弁護士費用（高額） | 債務名義を得る（2〜4ターン） | 費用が回収額を上回ることもある |
| 差押えを申し立てる | 債務名義または執行力ある公正証書 | 手続費用 | +25pt | 相手を倒産に追い込む |
| 債権届出をする | 相手が法的整理に入った | 0円 | 配当（一般に数%） | ほぼ戻らない |
| 貸倒損失を計上する | 年度末のみ | 0円 | — | 納税額が減る（§5.14）。回収を諦める |

このメニューを**焦げてから初めて開くプレイヤーは、ほとんどのアクションが「前提を満たさない」でグレーアウトしていることに気付く**。これが §1.2 の3番目の学びを届ける仕掛けである（表示の詳細は §9.5）。

| 信用調査を依頼する | 信用スコア・反社関係・休眠会社の買収・交渉余地の正確な値が分かる | 数万円 |
| 現物を確認する | 取引に実体があるかを確かめる（§4.10） | 交通費 |
| 保全条件を追加交渉する | 既存取引先から保全を取る。成否は交渉余地で決まる（§6.3） | 0円 |
| 価格転嫁を交渉する | 仕入価格の上昇分を売価に反映する | 決裂で取引縮小・失注のリスク |
| 電子記録債権への移行を交渉する | 第24ターン以降、手形取引を継続できるようにする | 決裂で取引が止まる |
| ファクタリングを使う | 売掛債権を即現金化（§5.3） | 債権額の5〜15% |
| 手形を割引する | 手形を早期に現金化 | 割引料（サイトに応じて増える） |
| 借入をする | 現金を増やす | 利息が固定費に乗る。返済が続く |
| 従業員を増やす | 引合い件数が増え、**アクション枠が+1される** | 固定費が月+30万円 |

アクション枠を従業員数に紐付けるのは、「与信管理と債権管理には人手がかかる」ことを表現するためである。**枠を増やすには固定費を上げるしかない**ので、これも投資判断になる。

### 6.9 判定モデル（実装のための数値定義）

ここまでの修正値がどこに加算されるのかを確定させる。**実装はこの節を仕様として読む。**

#### (a) 遅延の発生

```
月次遅延確率 = 業種の基準値（§6.2）
             × 格付係数（最上位0.5 / 上位0.7 / 中位1.0 / 下位1.5 / 要注意2.0 / 格付なし2.0）
             × 条件変更係数（支払条件の変更要請に応じた後は 1.5）
```

#### (b) 遅延から法的整理への遷移

各ターン開始時に判定する。

| 遷移 | 基準確率 | 修正 |
|---|---|---|
| 遅延 → 入金（解消） | 60% | 督促・催告を実行していれば +15pt |
| 遅延 → 長期遅延 | 40% | 上記の裏返し |
| 長期遅延 → 法的整理 | 25%／ターン | 支払計画を合意していれば 10%／ターン |
| 長期遅延 → 入金（解消） | 15%／ターン | 内容証明・差押えを実行していれば +15pt |

#### (c) 保全状況別の基準回収率

法的整理・事業停止に至った債権について、**基準回収率**を保全状況で決める。ここに §6.7 の回収率ボーナスを加算し、上限100%でクリップする。

| 保全状況 | 基準回収率 |
|---|---|
| 何も取っていない | 0〜10% |
| 期限の利益喪失条項のみ | 0〜15% |
| 所有権留保 | 30〜60% |
| 公正証書（執行力あり） | 50〜80% |
| 連帯保証人 | 40〜90%（**極度額でキャップ**。未設定なら0%） |
| 物的担保 | 70〜95% |
| 相殺できる範囲 | 100%（買掛金の額まで） |

**複数の保全を取っている場合は、次の順で計算する。**

1. **相殺できる範囲を先に確定する**（買掛金の額まで100%）
2. 残額に対して、保全のうち**基準回収率が最も高いものだけ**を適用する（max を採り、加算はしない）
3. §6.7 のボーナス（督促・催告・支払計画など）を加算し、100%でクリップする

加算にすると公正証書と物的担保を両方持つだけで常に全額回収になり、回収アクションを選ぶ意味が消える。

**取り込み詐欺（§4.9）と架空循環取引（§4.10）だけは例外で、保全状況に関わらず基準回収率0%とする。** 相手が消えている、または債権自体が架空だからである。この例外を設けることが、「予防しか手段がない類型がある」という学習を成立させる。

#### (d) 信用スコアと格付の対応

§4.4 の表のとおり（70以上=最上位／62〜69=上位／54〜61=中位／46〜53=下位／45以下=要注意／スコアなし=格付なし）。

**スコアはイベント時にのみ変動する。毎ターンのランダムな微変動は入れない。** 微変動を入れると格付の境界（54／62／70）を行き来して1社あたり上限が上下に揺れ続け、枠管理が破綻する。変動させるのは次の場合だけ。

- 遅延の発生（−5）、長期遅延への移行（−12）
- 支払条件の変更要請に応じた（−3）
- 固定イベント（第20ターンの主要取引先の急落など）
- 24ターン以上、遅延なく取引を継続した（+3）

#### (e) 交渉余地の初期値

| 信用スコア | 余地の初期値 |
|---|---|
| 62以上 | 1〜2（交渉力が強い） |
| 46〜61 | 2 |
| 45以下・スコアなし | 2〜3（売ってほしいので譲歩する） |

#### (g) 引合い件数の分布

| 件数 | 確率 |
|---|---|
| 0社 | 15% |
| 1社 | 35% |
| 2社 | 35% |
| 3社 | 15% |

期待値1.5社／ターン（年18社）。従業員を1人増やすごとに**期待値+0.5社**（分布を1件分ずらす）。

#### (h) 取引先ごとの粗利率

対価トレードの「売価を1%下げる」（§6.3）は取引先単位の値引きなので、**粗利率は全社一律ではなく取引先レコードごとに保持する**。初期値は16%で、値引きするごとに1ポイント下がる。会社全体の粗利率は各社の加重平均として計算する。

#### (f) 税

```
課税所得 = 年間営業利益 − 当期に計上した貸倒損失
納税額   = max(0, 課税所得) × 30%
```

**営業利益は焦げ付き損失を含まない値として計算する。** 含めてしまうと、貸倒損失を計上したときに二重控除になる。焦げ付きは「回収不能額が確定した時点で自己資本から直接減らし、貸倒計上したときにはじめて損金になる」という扱いにする。

年度末（第12・24・36ターン）に一括で計算する。**欠損金の繰越は扱わない**（赤字の年は納税0で、翌期に繰り越さない）。税制の学習は貸倒計上の判断だけに絞る。

### 7.3 罠プールと抽選 ―― リプレイ性の確保

固定イベントで罠の内容とターンを固定すると、**2周目は3手打つだけで全部無効化できる**。そこで罠は抽選する。

**プール（4種）**: 取り込み詐欺（§4.9）／架空循環取引（§4.10）／反社会的勢力（§5.15）／回し手形の振出人倒産

- 1回のプレイで**2〜3種を抽選**する
- **対象の取引先と発火ターンを ±4ターンの窓でランダム化**する
- 助走 → 本番という学習ビートは保つ

これによって「第7ターンの取引先を調べる」という暗記が効かなくなり、**誰を疑うかを毎回判断する**ことになる。アクション枠が有限（§3.2）なので総当たりもできない。

#### 「怪しいが本物」を毎回1〜2社混ぜる

罠だけを配ると「兆候があれば断る」が万能の正解になり、調査する意味が消える。そこで**登記に危険信号があるが実需のある会社**を毎回1〜2社混ぜる（本店移転歴があるが業績は堅実、事業目的が雑多だが実際に多角経営している、など）。

- 登記確認だけでは罠と区別がつかない。**信用調査まで打てば区別できる**
- 断ると健全な取引先を失う。エンディング（§8.4）で「断ったが健全だった相手」として金額が示される

これで調査が「兆候を見つける作業」から**「兆候の意味を切り分ける判断」**に変わる。過剰な慎重さにもコストがあることが体感される。

## 8. 学習コンテンツの設計

### 8.1 解説カードを2層にする

カードは全**30枚**。うち**必須14枚**を「その場で必ず表示する短いカード（200字）」とし、残りを「用語帳で読める詳細カード」にする。

v2.1 では48枚すべてをその場で表示する設計だったが、**失敗時カードが連続する終盤で読み飛ばしが起きる**。枚数を絞り、さらに2層に分けた。

**データ構造**:

| フィールド | 型 | 内容 |
|---|---|---|
| `id` | 文字列 | 一意の識別子（例: `payment-site-basics`） |
| `category` | 列挙 | `商習慣` / `与信管理` / `債権保全` / `債権回収` / `不正の見抜き方` / `在庫と仕入` / `法令` / `会計` |
| `tier` | 列挙 | `必須`（その場で表示） / `詳細`（用語帳のみ） |
| `title` | 文字列 | 見出し。断定形の一文にする（例: 「催告は延命、債務承認は更新」） |
| `body` | 文字列 | 200〜400字。必ず具体例を1つ含める |
| `source` | 文字列（任意） | 出典URLまたは条文名。法令カードは必須 |
| `trigger` | 列挙 | 発火条件 |

**発火のタイミング**:

1. **失敗時**（損をしたとき）: 「何を見落としたか」。**最も重視する**
2. **成功時**: 「なぜそれが正解だったか」
3. **選択の直前**（警告として）: 成立しない支払条件を選んだときなど
4. **グレーアウトを見たとき**: 使えない手段をクリックしたとき、「なぜ使えないか」

4番目は本設計特有の仕掛けである。**できないことに触れた瞬間に学ばせる。**

### 8.2 用語帳

- カテゴリ別のタブで分類
- 未獲得のカードは「？？？」として枠だけ見える
- 獲得率をヘッダーに常時表示（例: `用語帳 18/30`）
- **勝利条件には含めない**（§3.4）。独立した達成として表示する

### 8.3 期末の3行振り返り

36ターン後の振り返りだけでは遅い。決算フェーズ（第12・24・36ターン）で3行だけ出す。

```
今期あなたが取った保全: 2件 ／ 取り逃した機会: 5件
今期の焦げ付き純損失: 320万円（累計売上の 0.7%）
総与信枠の平均使用率: 88% ／ うち上位1社に 31%
断った取引の累計額: 月1,240万円分
```

総与信枠の使用率と1社集中度を入れたのは、枠の配分が v3.0 の中心だからである。集中度が数字で返ると §4.5 の学習が定着する。

**まだ立て直せる時期に自分の傾向を見せる**のが目的である。

### 8.4 エンディングの振り返り

- 現金・自己資本・月商の推移グラフ
- **各債権について「取引開始時に何を取っていたか」と「結果」の対応表**（最大の学びなので目立たせる）
- **回避した損失**: 断った相手・調べて売らなかった相手が実際に焦げたかを裏で判定しておき、金額で示す。逆に「断ったが健全だった相手」も見せ、**過剰な慎重さにもコストがある**ことを伝える
- 一度も使わなかった回収手段の一覧と、使える状況を作るには何をすべきだったか
- 獲得できなかったカードの一覧
- 「次はこうしてみよう」の提案3件

## 11. 実装方針

| 項目 | 方針 |
|---|---|
| 形態 | 単一のHTMLファイル。`<style>` と `<script>` をインラインに持つ |
| 外部依存 | なし。CDN・外部フォント・外部画像を使わない。アイコンは絵文字とCSSで表現 |
| フレームワーク | 使わない。状態は素のJavaScriptオブジェクト、描画は関数で行う |
| 数値の管理 | ファイル先頭の設定オブジェクトに全数値を集約する。§6.9 の判定モデルはそのまま定数表として写す |
| **履歴の記録** | §9.5 の表示に必要なため、**保全の取得履歴（いつ・何ptで取ったか）、納品物の転売時期、各アクションの実行ターン、交渉余地の推移**をすべて保持する。後から「いつまでなら取れたか」を計算できる構造にする |
| **機能の開放ターンの記録** | §9.5 の「いつまでなら取れたか」表示は、**その時点で開放されていた機能しか挙げてはならない**（§3.5）。保全がロックされていた第1〜7ターンの契約について「取れました」と表示すると、取れなかったものを責める形になり学習が成立しない。開放ターンを保持し、表示時に照合する |
| **調査結果の遅延** | 調査アクションは結果判明ターンのフィールドを持ち、**翌ターンに結果を反映**する（§6.3） |
| 回収アクション | データ駆動で定義する。各アクションに「前提を満たすか判定する関数」「満たさない理由の文言」「いつまでなら満たせたかを返す関数」を持たせる |
| 解説カード | 配列として定義。`tier` で必須／詳細を分け、本文と出典をロジックから分離する |
| 罠 | プールから抽選する構造にする（§7.3）。対象社とターンを乱数で決め、シード値を保存して再現できるようにする |
| テーマ | ライト・ダーク両対応 |
| 保存 | 1スロット。ブラウザのストレージにJSONで保存 |
| レイアウト | タブレット以上の画面幅を想定。表とログは各要素の内部で横スクロールさせ、ページ全体が横スクロールしないようにする |

### 実装後の確認項目

1. 手形と長期サイトを受け続けると、損益が黒字のまま現金が尽きて倒産する
2. 保全を何も取らずに進めると、§9.5 の「使えない手段」がずらりと並び、それぞれに「いつまでなら取れたか」が表示される
3. 保全を取った取引先と取らなかった取引先で、回収額が明確に違う（§6.9 の基準回収率どおり）
4. 動産売買先取特権が使えるのは、納品物が残っている短い期間だけである（第27ターンで1ターン待つと使えなくなる）
5. 連帯保証人の極度額を空欄にしたまま進めると、請求時に無効になる
6. 「末締め・当月20日払い」を選ぶとガード条件で弾かれ、警告が出る
7. **取適法の施行（第10ターン）後も、通常の卸売取引では手形での受取が続く。** 消えるのは配送外注先への手形払いとPB受託分だけである。手形が本当に使えなくなるのは第24ターン
8. 罠の助走を調べずに限度額を引き上げて出荷すると全損し、回収画面の全項目がグレーアウトする
9. 儲かる話に乗ると、いったん利益が出た後に回収不能が発生する。「現物を確認する」で事前に見抜ける
10. 仕入方針を「見込み仕入」にしたまま仕入価格高騰を迎えると、高値の在庫を抱えて損失が確定する
11. 仕入方針を「受注仕入」にすると、突発の大口注文で失注する
12. **新規を全部断り続けると、発注減少と固定費の年次上昇で3年目に赤字化し、現金が尽きる**（守りに入るだけでは勝てないことの確認）
13. 総与信枠が有限であるため、新規1社を取るには既存の限度額を削る必要がある
14. 2周目に罠の種類・対象社・発火ターンが変わる
15. §9.1 の焦げ付き純損失ゲージが、プレイ中つねに勝利条件との距離を示している
16. **総与信枠が満杯のとき、既存の限度額を減らさない限り新規を取れない**（ゼロサムの確認。§9.2 の「枠の遊び」列から剥がす操作が機能するか）
17. **信用調査の結果が翌ターンに出るため、当月の引合いは調べずに判断せざるを得ない**（§6.3 の確定解防止が効いているか）
18. **一部手形の相手では、同じ限度額で現金払いより出荷可能額が約3割少ない**（§6.4 の2行表示が正しい数字を出しているか）
19. **§9.5 の「いつまでなら取れたか」表示に、保全がロックされていた期間のターンが現れない**（§3.5 の実装制約の確認）
20. 保全を複数取った相手では、基準回収率が加算されず最も高いもの1つだけが適用される（§6.9(c)）
21. スコアが格付境界を毎ターン行き来しない（§6.9(d) の変動をイベント時に限定した確認）

## 付録A: 採用しなかった選択肢

| 検討したもの | 採用しない理由 |
|---|---|

## 付録B: 調査記録（倒産統計と失敗事例）

§4.8 の失敗要因を選ぶ根拠として調べた統計・事例を記録する。**ゲームの数値パラメータはこれらの統計値を直接使っていない**（§0）。統計は「どの失敗要因を題材に選ぶか」の判断根拠として使った。

### B.1 原因別倒産（2025年度、東京商工リサーチ）

| 原因 | 件数 | 構成比 |
|---|---|---|
| 全国企業倒産（総数、負債1,000万円以上） | 10,505件（前年度比+3.6%、12年ぶりの高水準） | — |
| **販売不振** | 8,478件（前年度8,261件から+2.6%、2年連続8,000件超） | 約8割（本書での算出） |
| 不況型倒産（販売不振＋売掛金回収難＋業界不振の合計） | 8,608件（前年度8,389件から+2.6%、4年連続増） | **82.5%** |

上の2行の差から、**売掛金回収難と業界不振の合計は130件**。したがって「売掛金回収難」を直接の原因とする倒産は**多くても全体の1.2%未満**である（この引き算は本書での算出であり、公表値ではない）。

設立10年未満の企業に絞った内訳は、販売不振1,467件（70.3%）、放漫経営230件（11.0%）、**他社倒産の余波（連鎖倒産）154件（7.3%）**、赤字累積105件（5.0%）。中小企業庁の『倒産の状況』でも原因の約73%が販売不振である。

放漫経営は162件→194件で4年連続増加（過去10年の最多）、経営者の病気・死亡は316件→350件で2000年度以降の最多。

### B.2 統計の主因と本ゲームの主題とのずれ

**本ゲームは統計上の最大の原因である「販売不振」を主題にしていない。** 意図的な選択であり、理由は3つ。

1. **原因分類は引き金をひとつ選ぶ方式**である。資金繰りの破綻（黒字倒産）で力尽きた会社も、売上が伸び悩んでいれば「販売不振」に分類される。分類の粒度が、回収サイトのズレという実態を覆い隠している面がある
2. **販売不振は商習慣や法令の知識では防げない**。売れないのは市場・商品・営業力の問題である。一方、回収難・連鎖倒産・詐欺被害は**知識で予防できる**。教材としての価値は件数の多さに比例しない
3. **一撃の大きさは構成比に表れない**。売掛金回収難は1.2%未満だが、起きた会社にとっては会社が消える出来事である。連鎖倒産の7.3%も与信管理の射程内にある

ただしこれを理由に「売れないリスク」を消してはいない。発注減少・市場縮小のイベント（§7.2）と固定費の年次逓増（§2.4）で、**与信管理を完璧にこなしても業績は悪化しうる**ようにしてある（§11 の確認項目12）。

### B.3 卸売業に絞った傾向（帝国データバンク）

- 卸売業の倒産は増加傾向。2025年12月の卸売業の倒産は105件で、前年同月の86件から22.1%増加。2025年7月時点でも前年同月の84件から105件へ増え、**全業種で最も高い25.0%の伸び**。特に繊維・衣服・繊維製品卸売の増加が大きい
- 2025年の「物価高倒産」は949件で過去最多。原材料・燃料費の高騰に加え、人件費の上昇に耐えきれないケースが目立つ
- 原材料・人件費・物流費・エネルギーの負担が小規模企業を圧迫し続けている

> 注: 帝国データバンクと東京商工リサーチは集計基準が異なるため、両社の件数を並べて差を論じてはいけない。本書は原因別構成比を東京商工リサーチ、卸売業の月次動向を帝国データバンクから引用しており、**同一の母数ではない**。
